# 贪吃蛇 · 课间小游戏

一个零依赖的静态小网页：深蓝与金色的贪吃蛇。方向键或屏幕方向键控制，吃到果实加分变长，撞墙或撞到自己就结束。没有账号、没有云端同步。

## 玩法

- 点击「开始游戏」，或在开始界面按任意方向键开始。
- 用键盘 `↑` `↓` `←` `→`，或手机上的方向按钮控制移动；不能直接反向掉头。
- 每颗果实 **+10 分**、蛇身 **+1 节**，最高分即时更新。
- 撞墙或咬到自己：弹出「游戏结束」提示，显示本局得分和最高分；点「再来一局」或按方向键即可重开。
- 手机窄屏会自动显示方向按钮；开始后收起引导文案，让棋盘和按钮尽量留在同一屏。

## 如何运行

推荐用本地静态服务器：

```powershell
cd C:\Users\zeng\Documents\deepseek-harness\default-workspace
python -m http.server 8000
```

然后打开 <http://localhost:8000>，按 `Ctrl+C` 停止服务器。

也可以直接双击 `index.html`。浏览器对 `file://` 下的本地存储策略不一致，用服务器最稳；如果浏览器禁止本地存储，只有最高分无法保留，游戏本身仍可玩。

## 刷新后的行为

- 最高分保存在浏览器 `localStorage`，键名 `snake-best-score:v1`。刷新页面、关闭再打开浏览器，最高分仍在。
- 当前这一局不会恢复：刷新后回到开始界面，分数归 0、蛇长回到 3。
- 换浏览器、无痕窗口或清除站点数据，最高分会丢失。
- 没有账号和云端同步；如果存储被禁用，最高分只在当前页面打开期间有效。
- 没有暂停功能。切到后台再回来时，蛇可能已经继续移动并撞墙。

## 手动验收步骤

1. 打开页面，点「开始游戏」，依次按 `↑` `↓` `←` `→`：蛇按对应方向移动；尝试按反方向不会瞬间掉头。
2. 控制蛇吃到一颗果实：分数从 0 变 10，长度从 3 变 4；最高分同步变成 10。
3. 继续移动直到撞墙：出现遮罩弹窗，标题为「撞到墙了」，本局得分和最高分正确；点「再来一局」能重新开始。
4. 按 `F5` 刷新：最高分仍然保留，当前局回到开始界面，分数 0、长度 3。
5. 刷新后按方向键直接开始新一局：蛇会朝该方向移动；游戏结束时弹窗可以再次出现。
6. 撞自己：吃到至少两颗果实（长度 ≥ 5）后，快速绕一个小圈撞向自己的身体，弹窗标题应为「咬到自己了」。
7. 手机/窄屏：开发者工具选 375 × 667，再试 320 × 568。页面不应出现横向滚动条；开始后点屏幕方向键能控制；结束弹窗完整落在视口内；375px 下开始后棋盘与完整方向键在同一屏。
8. 额外核对：如果本局得分超过原最高分，弹窗会显示「新纪录」小标签；0 分结束时不显示。
